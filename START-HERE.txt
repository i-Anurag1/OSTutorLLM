OSTutor - quick start

1. Install Docker Desktop  (https://www.docker.com/products/docker-desktop)
2. Install Ollama          (https://ollama.com/download)   [optional but recommended]
3. Windows: double-click RUN.bat       macOS/Linux: scripts/start.sh
4. Open http://localhost:3000
   Demo logins: student@ostutor.local / Student123!   faculty@ostutor.local / Faculty123!   admin@ostutor.local / Admin123!

Without Ollama the tutor still answers, directly from your notes ("extractive" mode).
The first start downloads two retrieval models in the background; search is usable immediately and upgrades itself.

Check everything offline (no Docker needed):  python scripts/verify.py
Fine-tune your own model:                     see training/README.md
Full documentation:                           README.md
