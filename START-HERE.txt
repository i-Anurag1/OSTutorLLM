OSTutorLLM FINAL - OPTION 1

1. Install Docker Desktop.
2. Install Ollama: https://ollama.com/download
3. Make sure Ollama is running.
4. Run RUN.bat on Windows.
5. Open http://localhost:3000

No cloud API key is required. The app uses local Qwen3 14B through Ollama.
The first startup also downloads BAAI/bge-large-en-v1.5 and BAAI/bge-reranker-base automatically inside the Docker Hugging Face cache.

If you want a cloud OpenAI-compatible provider instead, set LLM_BASE_URL, LLM_API_KEY and LLM_MODEL in .env.
